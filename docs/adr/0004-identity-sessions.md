# ADR 0004 — هویت: نشست سمت‌سرور مات به‌جای Refresh Rotation

- وضعیت: پذیرفته‌شده (فاز ۱)
- تصمیم: نشست‌ها توکن مات تصادفی در کوکی `ishan_sid` (HttpOnly، SameSite=Lax، Secure در production) هستند؛ در پایگاه داده فقط هش SHA-256 نگهداری می‌شود. انقضای بیکاری لغزنده + انقضای مطلق. ابطال فوری و لیست نشست‌ها ممکن است.
- مجوزها به‌صورت آرایه کلید در نقش ذخیره می‌شوند؛ کاتالوگ مجوزها در کد است (`@ishan/contracts`).
- CSRF: بررسی هدر Origin برای درخواست‌های تغییردهنده + SameSite.
- رمز: Argon2id؛ قفل حساب پس از ۵ تلاش ناموفق؛ TOTP با AES-256-GCM برای راز.
- ممیزی: جدول `audit_logs` فقط‌افزودنی (تریگر پایگاه داده UPDATE/DELETE را رد می‌کند).
- CI: هشدارهای drift مهاجرت و خلاصه خطا به‌صورت commit comment ارسال می‌شود (لاگ‌ها در دسترس نیستند).
- UI: پراکسی همان‌مبدأ `/api` → `API_INTERNAL_URL` تا کوکی و CSRF ساده بماند.
