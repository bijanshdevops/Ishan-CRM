# ADR 0001 — مونولیت ماژولار با مونوریپو

- **وضعیت:** پذیرفته‌شده
- **زمینه:** تیم کوچک، مقیاس اولیه حدود ۵۰ کاربر هم‌زمان و ۱ میلیون رکورد.
- **تصمیم:** یک API (NestJS) و یک Worker، ماژول‌های دامنه با مرز مشخص، مخزن واحد با pnpm workspaces و Turborepo.
- **پیامد:** پیچیدگی عملیاتی کمتر؛ جداسازی بعدی ماژول‌ها ممکن می‌ماند چون ماژول‌ها فقط از طریق سرویس‌ها و رویدادها با هم ارتباط دارند.
