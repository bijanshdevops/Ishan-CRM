# ADR 0002 — پشته فناوری و نسخه‌ها

- **وضعیت:** پذیرفته‌شده
- **تصمیم:** Next.js 16، React 19، NestJS **11** (Fastify)، PostgreSQL 16، Prisma **7** (generator `prisma-client`، آداپتر `pg`)، Zod، Vitest، TypeScript 5.9.
- **چرا NestJS 11 و نه آخرین major:** نسخه ۱۲ در زمان فاز ۰ منتشر شده بود؛ برای پرهیز از ریسک ناسازگاری اکوسیستم (nestjs-pino، swagger) روی ۱۱ پایدار ماندیم. ارتقا در فاز سخت‌سازی بررسی می‌شود.
- **چرا Prisma 7 و نه RC نسخه ۸:** نسخه latest در npm یک RC است و برای تولید مناسب نیست.
- **محل Prisma:** `apps/api/prisma` (و نه ریشه مخزن) تا به API متصل بماند؛ این با پیش‌نویس سند معماری اندکی تفاوت دارد.
