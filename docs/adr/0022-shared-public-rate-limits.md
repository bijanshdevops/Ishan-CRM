# ADR 0022 — محدودکننده‌های بقیه‌ی endpointها هم در Redis

وضعیت: پذیرفته‌شده

## زمینه

ADR 0018 فقط محدودیت ورود را به Redis برد و بقیه‌ی محدودکننده‌ها را عمداً حافظه‌ای گذاشت. با چند نمونه‌ی API،
هر نمونه شمارنده‌ی خودش را دارد و سقف واقعی «تعداد نمونه × سقف» می‌شود. پنج محدودکننده مانده بود:

| کلید                      | سقف                              | کاربرد                             |
| ------------------------- | -------------------------------- | ---------------------------------- |
| `verify-email:ip:<ip>`    | ۲۰ در دقیقه                      | `POST /auth/verify-email` (عمومی)  |
| `unsubscribe:ip:<ip>`     | ۳۰ در دقیقه                      | `POST /public/unsubscribe` (عمومی) |
| `verify-request:<userId>` | `EMAIL_VERIFY_REQUESTS_PER_HOUR` | درخواست پیوند تأیید ایمیل          |
| `email-test:<userId>`     | `EMAIL_TEST_PER_HOUR`            | ایمیل آزمایشی اعلان                |
| `campaign-test:<userId>`  | `CAMPAIGN_TEST_PER_HOUR`         | ایمیل آزمایشی کمپین                |

## تصمیم

- هر پنج مورد از `RateLimitService` (ADR 0018) استفاده می‌کنند؛ سازوکار، Lua اتمیک، نام‌گذاری `rl:<کلید>` و
  fallback محلی هنگام نبودن یا قطع بودن Redis همان است. عددهای سقف و پنجره تغییر نکردند.
- کلیدها پیشوند کارکرد دارند تا شمارنده‌ی یک endpoint با دیگری قاطی نشود.
- `common/rate-limiter.ts` (پنجره‌ی حافظه‌ای) فقط به‌عنوان fallback داخل `RateLimitService` می‌ماند.
- پاسخ‌ها و کدهای خطا (`429 rate_limited`) دست‌نخورده‌اند.

## پیامدها

- سقف دیگر به تعداد نمونه‌ها وابسته نیست؛ با Redis قطع، هر نمونه سقف محلی خودش را اعمال می‌کند (باز هم کران‌دار).
- هر درخواستِ محدودشده یک رفت‌وبرگشت کوچک به Redis دارد (با timeout ۵۰۰ms؛ خطا یعنی fallback، نه شکست درخواست).
- IP از `req.ip` می‌آید؛ پشت پراکسی باید `trustProxy` درست تنظیم باشد (مثل ورود).
- فهرست محدودکننده‌ها دیگر حافظه‌ای نیست. محدودیت ارسال پیش‌فاکتور (`quote-delivery`) سازوکار جدای پایگاه‌داده‌ای دارد و
  در این ADR نیست.
- تست: Redis واقعی در CI دو نمونه‌ی API را در یک پردازش بالا می‌آورد و نشان می‌دهد پنجره‌ی ۲۰ و ۳۰ تایی IP
  بین آن‌ها مشترک است (درخواست بیست‌ویکم/سی‌ویکم از هر نمونه ۴۲۹ می‌گیرد).
