# کنترل‌های امنیتی — وضعیت فعلی

مبنا: بخش ۸ سند معماری (هم‌راستا با OWASP Top 10؛ بدون ادعای انطباق رسمی).

| الزام                   | وضعیت      | توضیح                                                                                                                                                       |
| ----------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| احراز هویت و نشست       | انجام      | نشست سمت سرور، Argon2id، قفل موقت، MFA (فاز ۱)                                                                                                              |
| مجوزدهی (A01)           | بخشی       | RBAC deny-by-default با تست برای هر Endpoint؛ **مجوز سطح رکورد (مالک/تیم) باقی‌مانده**                                                                      |
| تزریق (A03)             | انجام      | Prisma پارامتری، Zod روی هر ورودی، `strictObject` برای رد فیلد ناشناخته                                                                                     |
| XSS / CSP               | انجام      | CSP با nonce برای هر درخواست در `apps/web/src/proxy.ts` (`script-src` بدون `unsafe-inline`)؛ `style-src` فقط `unsafe-inline` به‌دلیل `style` در کامپوننت‌ها |
| CSRF                    | انجام      | بررسی Origin روی درخواست‌های تغییردهنده + کوکی `SameSite=Lax`                                                                                               |
| هدرهای امنیتی (A05)     | انجام      | `X-Content-Type-Options`، `X-Frame-Options`، `Referrer-Policy`، `Permissions-Policy`، `frame-ancestors 'none'`                                              |
| اسرار                   | انجام      | بدون `.env` در مخزن؛ اسکن gitleaks روی کل تاریخچه در CI (کار `secrets`)                                                                                     |
| زنجیره تأمین (A06)      | بخشی       | `pnpm audit` در CI، Dependabot (npm، Actions، Docker)؛ SBOM و Trivy باقی‌مانده                                                                              |
| ممیزی                   | انجام      | Audit Trail append-only برای عملیات حساس                                                                                                                    |
| همروندی (ETag/If-Match) | باقی‌مانده | هنوز پیاده نشده                                                                                                                                             |
| Rate limit با Redis     | باقی‌مانده | با Worker/Redis                                                                                                                                             |
| پشتیبان و بازیابی       | باقی‌مانده | فاز ۸                                                                                                                                                       |

## محدودیت CSP

برای اعمال nonce صفحات به‌صورت پویا رندر می‌شوند (`dynamic = 'force-dynamic'`)؛ برنامه پس از ورود است و پیش‌رندر ایستا کاربردی نداشت.
