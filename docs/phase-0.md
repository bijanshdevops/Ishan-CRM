# فاز ۰ — زیرساخت

## معیار دروازه

`docker compose up` سبز و CI موفق.

## وضعیت راستی‌آزمایی

| مورد                                               | وضعیت                                                         |
| -------------------------------------------------- | ------------------------------------------------------------- |
| بیلد و تست `contracts`, `i18n`                     | تأیید محلی                                                    |
| بیلد و تست `web`                                   | تأیید محلی                                                    |
| اعتبار `compose.dev.yml` (`docker compose config`) | تأیید محلی                                                    |
| SQL مهاجرت اولیه روی PostgreSQL 16                 | تأیید محلی                                                    |
| `prisma generate` + بیلد و تست `api`               | **در CI** — باینری Prisma در محیط توسعه ابری قابل دانلود نبود |
| بالا آمدن کانتینرها (`docker compose up`)          | **باید روی ماشین شما/CI** تأیید شود                           |
