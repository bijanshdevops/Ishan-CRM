# فاز ۴ — فعالیت‌ها و تاریخچه تعاملات

شامل: تماس، جلسه، وظیفه و یادداشت (یک مدل واحد)، ثبت سابقه‌ی کارهای انجام‌شده، یادآوری درون‌برنامه‌ای، فهرست وظایف (امروز / عقب‌افتاده / پیش‌رو / انجام‌شده)، تقویم ماهانه‌ی شمسی، و تایم‌لاین پرونده‌ی مشتری (فعالیت‌های انجام‌شده + تغییر مرحله‌ی فرصت‌ها). تصمیم‌ها در [ADR 0005](adr/0005-activities.md).

## API (`/api/v1`)

| مسیر                                            | مجوز                                 | توضیح                                                                                                                    |
| ----------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| `GET /activities`                               | `activities.read`                    | فیلتر نوع/وضعیت/مسئول (`me`)/مشتری/مخاطب/فرصت/بازه/عقب‌افتاده، جست‌وجو، مرتب‌سازی `due` یا `recent`، صفحه‌بندی با cursor |
| `GET /activities/calendar?from&to`              | `activities.read`                    | بازه حداکثر ۶۲ روز، حداکثر ۵۰۰ مورد (`truncated`)                                                                        |
| `GET /activities/reminders/due`                 | `activities.read`                    | یادآوری‌های رسیده‌ی کاربر جاری                                                                                           |
| `POST /activities`                              | `activities.write`                   | ایجاد (برنامه‌ریزی‌شده یا ثبت سابقه)                                                                                     |
| `PATCH /activities/:id`                         | `activities.write` + مالکیت          | ویرایش                                                                                                                   |
| `POST /activities/:id/{complete,reopen,cancel}` | `activities.write` + مالکیت          | چرخه‌ی عمر                                                                                                               |
| `POST /activities/:id/reminder/dismiss`         | `activities.write` + مالکیت          | بستن یادآوری                                                                                                             |
| `DELETE /activities/:id`                        | `activities.delete` + مالکیت         | حذف نرم                                                                                                                  |
| `GET /customers/:id/timeline`                   | `customers.read` + `activities.read` | تاریخچه، صفحه‌بندی با `before`                                                                                           |

«مالکیت» یعنی مسئول یا سازنده‌ی فعالیت باشید یا مجوز `activities.manage_all` (مدیر فروش و مدیر سیستم) داشته باشید. نقش‌ها: کارشناس فروش `read+write`، مشاهده‌گر `read`، مدیر فروش همه.

## تصمیم‌ها و محدودیت‌ها

- قواعد شکل فعالیت یک‌جا در `@ishan/contracts` است و پایگاه داده هم با `CHECK` آن‌ها را تضمین می‌کند.
- یادآوری فعلاً فقط درون‌برنامه‌ای است (زنگ بالای منو، بررسی هر ۶۰ ثانیه و هنگام بازگشت به صفحه)؛ ایمیل/پیامک نیاز به worker دارد و در فاز بعد (گردش‌کار و اعلان‌ها) تصمیم‌گیری می‌شود.
- تقویم و انتخابگر تاریخ شمسی‌اند و ساعت به وقت تهران است (UTC+03:30 ثابت)؛ ذخیره و API همچنان UTC.
- تکرار فعالیت، شرکت‌کنندگان و همگام‌سازی با تقویم بیرونی هنوز نیست.
